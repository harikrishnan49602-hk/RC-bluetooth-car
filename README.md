# RC-bluetooth-car
Bluetooth controlled car use ESP32, motor driver, and four DC geared  motors. The Dabble mobile app connects  Bluetooth and controls the car's forward, backward, left, and right movements. The ESP32 processes joystick commands and uses PWM to control motor speed. All four motors work together to provide smooth movement and easy wireless control.

## Bluetooth-Controlled Car working

This project uses an ESP32, a motor driver, four BO DC motors, and the Dabble mobile application to control a car wirelessly through Bluetooth. The user connects a smartphone to the ESP32 and controls the car using the gamepad in the Dabble app. When the forward button is pressed, all four motors rotate to move the car forward. The backward button reverses the motors, while the left and right buttons rotate the motors in opposite directions to turn the car. The ESP32 processes the commands and controls motor direction and speed using PWM signals. This project provides simple wireless vehicle control without requiring Wi-Fi or internet access.
